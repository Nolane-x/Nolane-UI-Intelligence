# Replacing Shape Substitution

## Parent Contract
**Required parent:** `preventing-generic-ui`.

## Decision Boundary
Own whether a material geometric representation should be kept, refined, replaced, or sent back for a new visual direction. Geometry is valid when it organizes information, encodes real data, supports interaction, expresses an owned motif, or deliberately serves the experiential thesis.

## Decision System
Build a **geometric stand-in inventory** for the highest-attention abstract elements and name the semantic job of each one. Run a **native-media counterfactual** using the strongest truthful alternative for the same job: product imagery, archival material, diagram, map, document, specimen, data visualization, direct manipulation, commissioned illustration, domain-derived 3D, or typography.

Apply an **information-gain removal test**: compare comprehension, hierarchy, task support, identity, and intended affect with the element removed and with the stronger alternative present. Retained abstraction requires **semantic geometry justification** that names what it organizes, encodes, affords, or expresses.

Evaluate accumulation across the whole surface. The **re-divergence threshold** is crossed when several high-attention slots carry little subject information, the subject world becomes visually absent, or local replacement still leaves the same generic composition.

## Evidence
Record slot, current representation, semantic job, subject-native alternative, comparison result, removal observation, keep/replace justification, global accumulation finding, and final decision.

## Output Contract
Emit `shape-substitution-audit` with material slots, abstract slots, justified slots, examples, protected geometry, replacement actions, global finding, and decision. Unresolved material substitution cannot PASS.

## Failure Traps
A blanket no-card rule; adding imagery without a semantic job; removing truthful data geometry; judging each panel locally while ignoring global repetition; choosing replacement by trend instead of product meaning.

## Falsification
Compare the current high-attention representation with the strongest truthful alternative. Then remove a known useful data or interaction geometry. A valid audit must distinguish low-information substitution from geometry that materially supports the product.

## Recovery
Repair the highest-attention low-information slots first, rebalance hierarchy, and render the full surface again. If subject specificity remains weak after meaningful replacements, return to visual direction rather than adding more decoration.
