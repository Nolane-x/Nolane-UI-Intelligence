# Designing affinity analysis workflows

Affinity mapping is useful for discovering patterns across many observations, but easy to manipulate unconsciously. Use this skill when researchers or teams cluster notes, incidents, quotes, or observations into higher-level themes.

## Decision ownership

Own unit-of-analysis rules, clustering procedure, facilitator behavior, source linkage, duplicate handling, disagreement capture, and theme naming. Decide when clustering is exploratory versus used to support a formal finding.

## Inputs and evidence

Collect atomic observations with sources, participant/session IDs, existing codes, research questions, and team hypotheses. Remove duplicates created by multiple observers of the same event or mark them as shared observation rather than separate evidence.

## Procedure

Start with sufficiently atomic evidence units. Cluster by observed similarity before naming high-level categories. Allow items to remain ungrouped or cross-linked when forcing one cluster would erase complexity. Track which raw observations support each group.

During collaborative synthesis, use silent initial grouping or independent passes to reduce anchoring by senior voices. Record disagreements and alternative clusterings when they affect interpretation. Name themes as explanatory patterns rather than vague nouns.

## Failure topology

Colorful boards can create false rigor. Duplicated notes inflate apparent frequency. Early theme labels bias subsequent grouping. Another failure is deleting inconvenient outliers to make clusters look cleaner.

A cluster can mix different user populations or contexts and hide why experiences diverge.

## Falsification

Re-run clustering with a second group or blinded subset and compare major themes. Inspect every theme for source diversity and counterexamples. Collapse duplicates and see whether the apparent pattern survives. Ask whether a theme predicts or explains anything beyond restating the notes.

## Output contract

Produce an `affinity-analysis-workflows-contract` defining evidence units, deduplication, clustering sequence, source traceability, disagreement handling, theme naming, counterevidence, and reproducibility checks.
