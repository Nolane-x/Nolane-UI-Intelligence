# Designing interview note synthesis

Interviews generate stories, needs, beliefs, language, and remembered behavior—not direct proof of every claimed action. Use this skill when turning interview notes into themes and product implications.

## Decision ownership

Own coding units, theme formation, participant weighting, contradiction handling, quote/context linkage, and boundaries between finding, hypothesis, and recommendation. Decide how frequency is represented without pretending a qualitative sample is statistical.

## Inputs and evidence

Collect transcripts/notes, participant attributes relevant to the question, interview guide, session context, researcher memos, and prior hypotheses. Preserve enough source context to interpret ambiguous statements.

## Procedure

Code meaning units with descriptive labels before forming themes. Compare across participants and actively search for disconfirming cases. Keep “said they do X” distinct from observed behavior elsewhere. Link every synthesized theme to supporting and challenging evidence.

Represent prevalence carefully using participant counts only when sampling and coding make that meaningful. Avoid percentages from tiny purposive samples. Separate participant language from the researcher’s abstraction and from downstream recommendations.

## Failure topology

Memorable quotes can dominate despite being outliers. Repeated mentions by one talkative participant may look like frequency. Another failure is collapsing contradictory needs into a vague average persona.

Recommendations can be written as findings, hiding the inference step.

## Falsification

Ask a second researcher to trace each theme to raw notes and identify counterexamples. Remove the most vivid quote and see whether the theme still stands. Compare synthesis against pre-study hypotheses to detect confirmation bias.

## Output contract

Produce an `interview-note-synthesis-contract` containing coding approach, themes, source links, counterevidence, participant/context boundaries, prevalence language, unresolved contradictions, and separated implications/recommendations.
