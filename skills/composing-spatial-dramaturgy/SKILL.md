# Composing Spatial Dramaturgy

## Parent Contract
**Required parent:** `composing-layouts`.

This child strengthens the parent and may not waive parent obligations.

## Decision Boundary
Own emotional sequencing of space: compression, expansion, reveal, monumental moments, quiet fields, institutional anchors, depth transitions, and viewport occupation. Do not override information architecture, responsive behavior, or task reachability.

## Product Truth
Logical magnitude is not visual magnitude. Sixteen menu destinations can still feel like a cramped dashboard if fixed chrome consumes the viewport and every surface uses the same pane grammar. Spatial drama must emerge from changing relationships and scale, not empty theatricality.

## Decision Model
Decompose magnitude into scope, data, spatial, institutional, temporal, network, and visual dimensions. Design a sequence: a compressed control zone can release into a vast model canvas; a quiet field can make an institutional anchor feel monumental; focused inspection can temporarily collapse peripheral chrome; reveals can expose deeper scale progressively. Specify `compression_zones`, `expansion_zones`, `monumental_scale_moments`, `quiet_fields`, `reveal_moments`, `institutional_anchors`, `depth_transition`, and `viewport_occupation`.

## Evidence
Provide annotated surfaces or layout states showing where each spatial role occurs and which magnitude dimension it supports. A claim of “huge” satisfied only by more pages fails evidence.

## Output Contract: `spatial-drama-contract`
Return the canonical `spatial-drama-contract` artifact with explicit status, evidence references, unresolved unknowns, and downstream routes. Missing material evidence must remain UNKNOWN/BLOCKED rather than being inferred from confidence.

## Failure Traps
More navigation equals more magnitude; permanent maximal canvas with no rhythm; oversized empty hero unrelated to work; cinematic transitions that harm high-frequency tasks; fixed chrome that defeats the stated scale; using zoom/3D solely as spectacle.
