# Claude Code adapter

Use NUI as an Agent Skill graph inside Claude Code without changing its core lifecycle.

## Discovery
A personal installation may use the runtime's skill directory (commonly `~/.claude/skills/`) or a cross-runtime Agent Skills location when supported. A project may keep the repository local and reference the bootstrap from project instructions.

## Tool binding
Map file edits and tests to Claude Code's native workspace/shell capabilities. Map browser, screenshot, semantic-tree, component registry, or design-source access to configured MCP/tools only after confirming they exist.

## Subagent review
Claude Code environments that expose subagents are a strong fit for NUI's independent critics: give the critic the contract, relevant design artifacts/render, obligations, and one critic skill—not the generator's full implementation narrative. The reviewer returns findings only.

## Degraded mode
When a browser or design source is unavailable, continue architecture/craft work if possible but leave runtime/fidelity obligations UNKNOWN. Do not claim a screen “looks right” from code alone.
