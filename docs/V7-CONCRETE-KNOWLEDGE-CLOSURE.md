# NUI v7 — Concrete Knowledge Closure

## Why v7 exists
The critique that drove this release identifies a real architectural asymmetry: NUI can be unusually strong at deciding **where an agent must think**, while mature design institutions and specialist libraries have accumulated concrete practice from years of production, user research, accessibility testing, platform embodiment, vertical workflow design, and implementation failures. The gap is **accumulated concrete design knowledge**: the difference between “**biết mình phải suy nghĩ ở đâu**” and “**đã sống trong bài toán đó hàng triệu giờ**.”

V7 does not answer that gap by copying third-party systems into 166 prose files or turning NUI into a giant component catalog. It creates four causal bridges: decision-dimensional authority, source-bound concrete pattern cards, implementation/agent-readable adapters, and rendered-perception verification.

## Closure map

### Adobe Spectrum 2 — craft and creative-professional maturity
The critique credits **Adobe Spectrum 2** with verified visual craft, professional creative workflow depth, implementation maturity and design-to-production lineage. V7 responds with `design-to-production-lineage`, `creative-tool-primary-surface`, `creative-density-with-legibility`, rendered type/material evidence, and explicit production lineage. Spectrum remains an external craft/production authority where applicable; NUI does not imitate Adobe trade dress.

### Apple HIG — platform-specific embodied craft
**Apple HIG** is treated as a scoped platform authority, not one reference among many. `routing-to-ui-authorities` boosts platform-convention authority only on Apple platforms; `adapting-platform-conventions` now requires platform authority deference and device/input evidence. Cross-platform NUI reasoning remains useful above that layer, but it may not overwrite hardware ↔ software harmony with generic web defaults.

### GOV.UK and USWDS — institutional service evidence
**GOV.UK** and **USWDS** represent accumulated service research and accessibility practice. V7 adds institutional evidence debt, local-context revalidation and source-bound service cards such as eligibility-before-application, user-need-first structure, error recovery and research provenance. A copied service pattern cannot pass merely because upstream teams tested it; transfer assumptions and local evidence remain visible.

### React Aria and Radix — implementation evidence for semantics
The critique correctly distinguishes NUI saying “focus must be correct” from **React Aria** or **Radix** implementing and testing focus/keyboard/screen-reader behavior. V7 therefore routes component-semantics authority to tested semantic sources where applicable and introduces `orchestrating-implementation-authorities`. Visual libraries cannot displace that layer; visual treatment is adapted around semantic behavior or reimplemented with fresh proof.

### SAP Fiori — enterprise workflow semantics
**SAP Fiori** is represented as institutional enterprise authority for role/task, floorplan, object, draft/message and human-control patterns. NUI’s broad enterprise ontology no longer pretends to replace that accumulated practice. V7 can extract mechanisms, record context, and require local revalidation while keeping NUI responsible for cross-source conflicts and product-specific synthesis.

### Ant Design — concept to production UI
**Ant Design** contributes mature bridges from general concepts and cognitive principles to reusable enterprise components/patterns. V7 uses `concept-to-pattern-before-component` and production-lineage cards instead of treating “Natural/Meaningful/etc.” as aesthetic adjectives. Concrete reuse must remain bounded by domain and local semantics.

### Carbon — working code, patterns and production lineage
**Carbon** is recognized as a system of working code, patterns, design tools and human-interface guidance rather than “IBM components.” V7 tracks Carbon as enterprise/production authority and separately records **Carbon MCP** as an access adapter. The MCP endpoint lowers retrieval friction; it cannot inflate Carbon’s authority outside its scope.

### Atlassian / Rovo — AI × enterprise collaboration
**Atlassian** and Rovo are modeled as a targeted authority for AI collaboration patterns inside enterprise collaboration contexts. `designing-human-ai-interaction` now keeps host-system visual language primary for common UI while using AI-specific differentiation for agency, provenance, uncertainty, streaming and correction. Constant “AI sparkle” is an adversarial failure case.

### Shopify Polaris — deep vertical commerce
**Shopify Polaris** demonstrates why generic commerce ontology is not deep vertical knowledge. V7 makes Shopify authority sharply platform-scoped: Polaris is strong on Shopify surfaces but receives a large applicability penalty in generic commerce. Cards marked Shopify-only cannot leak into unrelated commerce packets.

### Primer — agent-readable design system
**Primer** is tracked both as a design/implementation source and through a Primer MCP adapter. This is the v7 pattern for agent-readable systems: query current component/API/accessibility guidance when Primer is relevant, while preserving `authority_escalation:false`.

### UI/UX Pro Max — speed and immediate answerability
**UI/UX Pro Max** exposes a real NUI weakness: a broad style/palette/font/product-rule database can answer quickly while a meta-reasoning framework keeps deliberating. V7 answers with the bounded concrete design packet and immediate synthesis grammar. Retrieval can seed a decision, but category scores never outrank explicit product constraints or replace provenance/contraindications. Style-database-default convergence is now a named regression.

### shadcn — open code productivity
**shadcn** shows that one inspectable installable component can sometimes be more valuable than thousands of reasoning tokens. V7 adds open-code as an implementation access mode and a `open-code-inspect-then-own` pattern. Once copied, the project owns semantics, accessibility, tokens, tests and maintenance; registry defaults are not final product design.

### Mantine — documentation for agents
**Mantine** demonstrates LLM-optimized documentation, agent skills and MCP access. V7 records these as separate adapters with live-verification requirements. The agent can hydrate current props/docs efficiently without treating the existence of MCP/skills as a quality score.

### React Bits, Aceternity and Magic UI — visual frontier
**React Bits**, **Aceternity**, and **Magic UI** stay visual-frontier sources. They can expand the set of possible animated, canvas, shader, typography and hero mechanisms. V7 deliberately does not copy their style into the skill graph and does not allow them to become semantic authority. `designing-domain-native-signatures` converts visual courage into a mechanism rooted in the product’s own subject world.

### Motion — specialist depth beats generic motion prose
**Motion** remains a specialist implementation authority for animation/layout/gesture/presence mechanics where selected. `designing-motion` now separates temporal meaning from engine mechanics and requires rendered before/transition/settled evidence plus reduced-motion semantic equivalence. NUI does not pretend one `designing-motion` skill replaces a motion engine.

## What changed structurally
V7 adds an authority mesh, 38 concrete source-bound pattern cards, a bounded synthesis grammar, agent-readable adapters, a rendered-perception rubric, eight new decision owners, deterministic v7 routes/completion gates, and 32 adversarial cases. The resulting system is intentionally hybrid:

`understand → resolve authority → retrieve concrete evidence → compile bounded decisions → orchestrate implementation → render → observe → criticize → repair/re-diverge → verify`

The target is not “NUI knows every design answer.” The target is **NUI knows when it should defer, what it must retrieve, what it can safely transfer, how to execute quickly, and how to prove the result survived in perception.**
