# NUI v8 — Agent Interoperability & Visual Media Intelligence

## Problem
NUI v7 can route deep UI knowledge and concrete authorities, but two causal gaps remain. First, an excellent NUI graph is costly if an agent harness cannot discover it without vendor-specific duplication. Second, generative agents often substitute generic geometry—cards, orbs, blobs, pseudo-topologies—for subject-native media, while external images and skill repositories introduce rights, trust and capability risks.

## Architecture
V8 has four bounded planes rather than a flat expansion of skills.

1. **Portable Agent Surface.** One canonical NUI graph is exposed through thin `.agents/skills` and `.claude/skills` bridges, a bounded MCP server, and a vendor-neutral CLI. Discovery protocol never changes authority; host permissions remain sovereign.
2. **External Skill Trust Firewall.** Third-party skills are treated as untrusted instruction/code supply-chain inputs. Material adoption requires immutable snapshot, content hash, license evidence, transitive executable/capability review, instruction/data quarantine, bounded adoption mode and reviewer.
3. **Visual Media Decision Engine.** Before filling space with interface geometry, the agent maps semantic media jobs and omission cost. Shape substitution is separated from legitimate geometry that encodes data, structure or affordance. External assets require asset-level provenance and rights evidence.
4. **Creative Toolchain Router.** Generation, 3D, design-canvas, animation, vector/raster, browser rendering and optimization are separate stages with explicit tool authority, file handoff and fallback. Every chain returns to actual rendered product states for validation.

## Copyright / source policy
NUI stores pointers, provenance and independently written mechanism summaries by default. It does not bulk-copy external skill or documentation corpora. Public readability is not reuse permission. Mixed-license repositories are reviewed at the exact skill/file level. Media search providers are discovery surfaces, never blanket license authorities.

## New owners
Exactly eight new decision owners cover harness export, external skill governance, media opportunities, rights-safe sourcing, custom domain assets, creative toolchains, shape substitution and rendered asset integration. No MCP-specific design skill is added because MCP is infrastructure, not a design decision owner.

## Completion
V8 completion inherits v1-v7. External skills require trust evidence; external media requires asset-level provenance; subject-native media tasks require media opportunity mapping and rendered integration; unresolved shape substitution can force `RE_DIVERGE`; creative tools require stage-authority plans.
