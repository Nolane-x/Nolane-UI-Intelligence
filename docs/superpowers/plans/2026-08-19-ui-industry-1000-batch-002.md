# UI Industry 1000 — Batch 002 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add exactly 100 independently authored UI specialist skills to NUI, growing the canonical graph from 274 to 374 without duplicate ownership or generated skill prose.

**Architecture:** Preserve the existing canonical graph and broad owners. Add ten manually authored skill clusters as specialist children, protect them with a Batch 002 acceptance test, then integrate an explicit 100-node graph map and update provenance/count documentation only after repository-wide verification succeeds.

**Tech Stack:** Markdown Agent Skills, JSON canonical graph, Python `unittest` contracts, existing NUI Python validator, GitHub Actions Verify NUI.

**Spec:** `docs/superpowers/specs/2026-08-19-ui-industry-1000-batch-002-design.md`

## Global Constraints

- Exactly 100 new `SKILL.md` bodies.
- No loop, template generator, macro expansion, bulk prose transformation, cloned body, or prompt-programmatic skill generation for skill prose.
- Graph/bookkeeping automation may manipulate explicit metadata only; it must never generate skill prose.
- Starting graph is 274; final graph is exactly 374.
- Historical 174-skill depth baseline and all Batch 001 slugs remain intact.
- Every skill owns a distinct decision/failure boundary, unique output, valid parent, falsifier, recovery path, and evidence-bearing output.
- Repository-wide tests and canonical validator must pass before merge.
