> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add exactly 200 independently authored UI-industry specialists to NUI, expanding the canonical graph from 474 to 674 without duplicate ownership or template-generated prose.

**Architecture:** Work on a stacked feature branch based on the Batch 003 474-node head. Lock all 200 identities/metadata in a failing acceptance test before prose exists, implement ten isolated 20-skill courts, then perform deterministic graph/documentation bookkeeping and remove all temporary mutation tooling before exact-head verification.

**Tech Stack:** Markdown skill corpus, JSON canonical graph, Python `unittest`, GitHub Actions, NUI release packet and validator scripts.

**Spec:** `docs/superpowers/specs/2026-08-20-ui-industry-1000-batch-004-200-design.md`

## Global Constraints

- Exactly 200 new `skills/<slug>/SKILL.md` files.
- No substantive skill prose may be produced by loop, template, macro, mass rename, or body generator.
- Shared headings are schema only; decision logic, failures, falsification, procedure, and output contract must be distinct.
- Each new skill has one unique output contract and a valid parent.
- Final canonical graph count is exactly 674.
- Temporary graph/finalization tooling must not survive the final merge candidate.
- Canonical verification workflow must finish read-only.
- No completion claim without exact-head evidence.
