# UI Industry 1000 — Batch 001 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add 100 independently authored specialist UI faculties to NUI, integrate them into the canonical graph, preserve provenance/ownership boundaries, and pass structural validation without loop-generated skill prose.

**Architecture:** Deepen existing broad owners rather than adding parallel top-level systems. Each specialist gets its own `skills/<slug>/SKILL.md`, graph node and unique output contract. A batch-specific acceptance test enumerates the 100 intended slugs and protects filesystem/graph/frontmatter/integrity invariants.

**Tech Stack:** Markdown Agent Skills, JSON skill graph, Python `unittest`, existing `scripts/nui-validate`, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-08-19-ui-industry-1000-batch-001-design.md`

## Global Constraints

- No loop-generated or Cartesian-product-generated skill prose.
- No bulk copying of third-party skill text.
- Every skill owns a distinct decision/failure class and keeps parent obligations.
- Automated tooling may validate/index/deduplicate/route, but may not author substantive skill bodies.
- All new nodes must reach `using-nolane-ui` through the canonical graph.
- Claims remain bounded to structural/authored-corpus evidence unless empirical evaluation is separately performed.
