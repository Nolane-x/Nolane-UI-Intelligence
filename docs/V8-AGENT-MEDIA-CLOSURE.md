# V8 closure — Agent Interoperability & Visual Media Intelligence

V8 closes five gaps left after v7:

- **Harness gap:** 174 deep skills are useless if an agent cannot discover them. Thin Codex/Antigravity/Claude bridges + MCP + CLI expose one canonical graph.
- **External-skill trust gap:** useful skill repositories can contain changing prompts, scripts, mixed licensing or overbroad capabilities. Snapshot/hash/license/capability/instruction-boundary gates now block blind adoption.
- **Shape-substitution gap:** anti-card rules alone can mutate into blob/orb/fake-graph UI. V8 tests whether geometry actually encodes meaning and forces `RE_DIVERGE` when generic abstraction displaces subject-native evidence.
- **Media-rights gap:** image search is separated from permission. Eight media source classes feed an asset-level provenance ledger rather than a “free image site” assumption.
- **Creative-tool gap:** NUI no longer acts as if a prose skill replaces Figma, Blender, image generation, renderer or animation engine. It routes those tools by stage, verifies live capability and brings output back through responsive/rendered validation.

The v8 graph adds eight owners only; progress is measured by new causal gates, not by skill count.
