## Admission boundary

A candidate remains admitted only if its final body demonstrates a consequential decision/failure class that the parent and siblings do not already own. If review finds that two candidates are merely a renamed version of one decision, one is removed or the inventory is revised before graph integration; the batch is not padded back to 200 with a cosmetic replacement.
