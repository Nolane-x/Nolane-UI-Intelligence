# UI Authority Intelligence v7

## Research thesis
NUI v7 treats external design knowledge as a graph of scoped authorities rather than a leaderboard of famous systems. A source can be excellent at component semantics and weak at art direction; another can be exceptional visual inspiration and carry no authority over focus, service workflow or platform behavior.

**Access protocol is not authority.** MCP, llms.txt, agent skills, structured docs and open-code registries reduce the cost of getting current context into an agent. They do not grant normative status. Every adapter points to an `underlying_authority`, requires live verification, and explicitly sets authority escalation to false.

## Source classes and the decisions they can own
- Platform systems can own target-platform convention when applicability is real.
- Institutional systems can contribute accumulated service, enterprise, commerce or creative-professional workflow practice.
- Tested headless/semantic libraries can own bounded interaction mechanics that their code/tests actually prove.
- Motion/render/data engines can own implementation mechanics, never product state truth by convenience.
- Visual frontiers can expand possibility space and reveal implementation mechanisms.
- Agent-readable adapters hydrate any of the above; they are transport.

## Mechanism, not trade dress
When NUI learns from external visual work, transfer **mechanism, not trade dress**. Extract the causal device—shared spatial continuity, a domain data-to-form mapping, a coordinated temporal sequence, a canvas interaction technique, a type/image hierarchy—then rebuild it from local product truth. Do not import recognizable branded copy, palette, illustration, composition, signature motifs or motion sequence merely because they demonstrate quality.

## Institutional evidence debt
A mature design system may have tested patterns, real service use, migration history and accessibility practice that NUI cannot recreate through prose. That is valuable. V7 records what the institution has evidence for, which assumptions differ locally, what remains unvalidated, and when local research is still required. Citations are not repayment of evidence debt.

## Concrete knowledge plane
The v7 concrete knowledge base stores narrow cards rather than broad aesthetic categories. Each card contains problem, decision, rationale, domains, decision dimensions, provenance claims, contraindications, validation obligations and transfer boundary. The immediate synthesis grammar selects only a bounded set of high-leverage decisions. Unresolved authority survives as a blocker instead of being silently replaced with a default.

## Agent-readable context
Live hydration is preferred when upstream changes rapidly. The agent context budget should contain only the decision question, target version/platform, relevant current API/guidance handles, constraints and next verification step. Giant documentation dumps are a retrieval failure, not research depth.

## Rendered perception
Planning quality cannot prove output quality. V7 therefore requires **rendered perception** for high visual ambition: material viewport/state capture matrix, attention hierarchy, actual resolved typography, signature visibility/removal cost, material/surface structure, reference comparison and critique/fix trace. Material motion adds temporal sequence and reduced-motion equivalence.

Visual regression is calibrated rather than naive. Pixel deltas are tied to renderer/environment and a justified tolerance because rasterization and anti-aliasing can vary. Numerical image similarity never becomes a universal aesthetic score.

## Live verification policy
Use live verification when source versions, platform guidance, AI tool adapters, APIs, component implementations or policies can drift. Preserve the project’s pinned version where relevant. A live source that describes a newer release cannot silently redefine an older pinned dependency.

## Stop conditions
Research may stop only when the decision dimension has an applicable authority or is explicitly unresolved; mechanism-bearing evidence and transfer boundary exist; agent adapters are version/currentness bounded; concrete decisions retain contraindications; and rendered claims have the evidence plane their ambition requires.
