# UI Source Intelligence v6

NUI v6 treats an external repository as a **research object**, not a bag of snippets. The registry is a retrieval index; it never grants permission to copy code or visual language by itself.

## Three source tiers

- **anchor** — current-wave artifact-level inspection exists. Even an anchor still requires a task-specific dossier before material use because product fit is contextual.
- **specialist** — canonical source and role are known, but the agent must inspect the role-specific artifacts live before the source may influence a material decision.
- **discovery** — lead only. Identity, status, license, role and currentness must be established first.

Popularity, star count and social visibility are deliberately absent from the authority model.

## Repository archaeology protocol

The research path is role-sensitive. An animated component gallery requires component source, demo context, dependency surface, motion/interruption behavior and reduced-motion evidence. A headless primitive requires state/interaction tests, keyboard-focus behavior and accessibility guidance. An icon family requires its catalog, construction grammar, naming/tag model and delivery boundary. A typography source requires script coverage, weights/axes and delivery/subsetting behavior. Graph editors, maps, code editors, terminal systems, AI-native UI and animation runtimes each carry different failure surfaces.

For material `adopt` or `adapt`, a high-drift source must be pinned to a current ref/commit. The dossier records every inspected artifact by path, what was learned there, mechanism evidence, contradictions, unread material, integration hazards, and why further reading is unlikely to overturn the current decision. **README + license alone can never authorize material or visual influence.**

## Cross-source synthesis

NUI assumes that strong products often combine sources, but it rejects library collage. Every synthesis assigns ownership for semantics, interaction, visuals and any additional layer such as motion or data rendering. Local product actions, states, accessibility contracts and tokens remain higher authority than foreign demo defaults. Conflicts must be resolved explicitly; foreign labels, radii, colors, focus assumptions and motion grammar are removed unless consciously re-derived into the local system.

## Registry breadth

v6 preserves the prior component/motion/design-system/data/editor/canvas/3D/mobile ecosystem and adds explicit source classes for icons, typography, design-token/style tooling, visual and accessibility testing, graphs/diagrams, geospatial UI, code editors, terminal UI, AI-native UI, creative rendering and animation-asset runtimes. The registry is intentionally reopenable: absence of a fit is a trigger for live research, not permission to hallucinate a library from memory.
