This document maps the supplied ATLAS-on-v4 critique to v5 mechanisms. “Closed” here means the repository now contains an explicit owner, deterministic invariant, route, schema, or adversarial specification for the failure class. It does **not** mean repository-only CI can prove every future model run produces a beautiful UI; runtime/model-eval-dependent claims remain bounded.

## Evidence status

Repository-level deterministic evidence verifies that these mechanisms, routes, manifests, schemas, mutations and release gates are structurally present and behave on their coded fixtures. Cross-model aesthetic uplift, blind human preference, and repeated agent-behavior improvement require an agent runtime and independent evaluation; v5 explicitly records those as external evidence rather than manufacturing a PASS from repository parsing.
